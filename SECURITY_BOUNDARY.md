# Security Boundary

This repository is PUBLIC_SAFE infrastructure only.

Allowed:
- generic algorithms;
- synthetic fixtures;
- schema validation;
- deterministic unit/regression tests;
- disclosure-safe GUI/tooling validators.

Forbidden:
- private repository checkout;
- credentials or secrets;
- private artifacts;
- real plugin source or binaries;
- proprietary DSP or product data;
- private operational state.

Anything uncertain stays PRIVATE_REQUIRED outside this repository.
